Mail Test Checklist

Redoslijed provjere prije prvog test slanja.

DashboardSend MailMail log

1. Endpoint provjera

Otvori: /api/operator/mail-batch/send Očekivano: JSON odgovor s ok=true, endpoint=mail-batch-send i allowed_senders: it@gnk-asg.hr, info@gnk-asg.hr.

2. DNS i provider

U provideru, Resend ili Brevo, moraju biti potvrđene adrese ili domena: it@gnk-asg.hr info@gnk-asg.hr U Cloudflare DNS moraju biti postavljeni SPF, DKIM i DMARC zapisi koje daje provider.

3. Test slanje

U /operator/mail-send/ odaberi prvo IT asistenta i pošalji test na beckuphome@gmail.com. Ako prođe, ponovi test s info@gnk-asg.hr. Nakon svakog testa otvori /operator/mail-log/ i provjeri zapis.

4. Pravilo

Ne slati batch svima dok test s obje adrese ne prođe. Batch slanje ostaje ograničeno na 30 primatelja.
