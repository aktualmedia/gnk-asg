Cloudflare Content Setup

Koraci za spajanje CONTENT_DRAFT_KV i Worker ruta za objave.

Admin AppAPI CheckPost Composer

1. KV namespace

Naziv: CONTENT_DRAFT_KV Svrha: spremanje draft/ready paketa iz Post Composer modula. Nakon kreiranja KV namespacea, spojiti binding u Worker: Binding name: CONTENT_DRAFT_KV Namespace: CONTENT_DRAFT_KV

2. Worker

Worker name: gnk-asg-content-publish-api Izvorni kod u repozitoriju: workers/content-publish-api/src/index.js Wrangler konfiguracija: workers/content-publish-api/wrangler.toml

3. Rute

Spojiti Worker na ove rute: gnk-asg.hr/api/operator/content/publish gnk-asg.hr/api/operator/content/list Preporuka: Zaštititi /api/operator/content/* kroz Cloudflare Access.

4. Varijable

OPERATOR_ALLOW_NO_ACCESS=false Privremeno samo za kontrolirani test može biti: OPERATOR_ALLOW_NO_ACCESS=true Nakon testa vratiti na false.

5. Test redoslijed

1. Otvori /operator/api-check/. 2. Provjeri Content publish endpoint. 3. Provjeri Content list endpoint. 4. Ako je 401, ruta postoji ali traži autorizaciju. 5. Ako je OK, otvori /operator/post-compose/. 6. Upiši probnu objavu kao draft. 7. Klikni Pošalji u backend. 8. Otvori /operator/content-list/ i provjeri je li zapis spremljen.

Napomena

Ovaj sloj u prvoj fazi ne mijenja javni statički portal. On sprema objave u backend KV kao draft ili ready zapis. Javno objavljivanje statičke stranice ostaje odvojeni zaštićeni deploy/write proces.
