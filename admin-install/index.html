GNK ASG Admin aplikacija

Ovo je skrivena instalacijska stranica za administratorsku mobilnu i desktop aplikaciju. Koristi se samo za ovlaštene osobe kojima je poveznica izravno dana.

Admin mobile

Za mobitel: otvorite ovu stranicu ili /admin-mobile/ u Chromeu ili Safariju, zatim dodajte aplikaciju na početni zaslon. Aplikacija traži lokalni PIN, a za stvarno slanje sadržaja koristi zaseban Cloudflare admin token.

Otvori admin mobile

Admin desktop

Za računalo: otvorite /admin-mobile/ u Chromeu ili Edgeu i instalirajte kao desktop aplikaciju. Otvara se u zasebnom prozoru i služi za nacrte objava, tekstove, fotografije i budući media operator.

Otvori manifest

Skriveni QR za admin app

Privremeno se koristi QR instalacijski tok dok se ne doda zasebni admin QR. Ova stranica i admin aplikacija ostaju noindex i nisu dio javnog menija.

Sigurnost: lokalni PIN nije dovoljan za objavu. Pravi administratorski token mora biti Cloudflare secret i ne smije se slati javno.
