# Investor readiness — V11

## Cilj
Pripremiti profesionalni investicijski paket bez objave povjerljivih ili neprovjerenih podataka.

## Obavezno prije javne objave brojki
- revizorsko izvješće
- financijski izvještaji
- registri društava
- vlasnička/UBO dokumentacija
- ugovori i IP dokumentacija
- porezno/računovodstveni status
- pravni rizici
- potvrđeni izvor za svaku javnu tvrdnju

## Javni investitor hub smije sadržavati
- opis društva
- parent/operating company model
- globalni prikaz
- tehnološki i komunikacijski stack
- data room strukturu
- roadmap
- opće rizike
- FAQ

## Ne objavljivati bez provjere
- točne financijske brojke
- projekcije povrata
- valuaciju
- broj zaposlenih grupe ako nije dokumentiran
- povjerljive ugovore
- neprovjerene registracijske tvrdnje
