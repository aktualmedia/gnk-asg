# App install/admin — V12

## Javni guest app
Putanja: `/install/`

Gosti mogu:
- skenirati QR kod,
- otvoriti PWA install stranicu,
- instalirati aplikaciju na mobitel ili računalo,
- koristiti javni portal, javni AI, kontakt, WhatsApp link i investor hub.

Gosti ne mogu:
- pristupiti adminu,
- čitati privatni inbox,
- izvršavati command,
- slati mail ili WhatsApp automatski,
- vidjeti secrets.

## Admin mobile app
Putanja: `/app/admin/`

Funkcije:
- privatni agent,
- command centar,
- status,
- self-test,
- MailOps,
- Communication,
- Investor,
- Downloads.

## Desktop admin app
Putanja: `/desktop/`

Namjena:
- instalacija kao PWA na računalu,
- široki admin workspace,
- release, status, MailOps i investor rad.
