# Javni i privatni agent

## Javni agent
- besplatan
- bez API troška
- lokalna knowledge baza
- javni JSON podaci
- nema admin ovlasti
- ne šalje mail/WhatsApp

## Privatni agent
- operativni
- priprema command JSON
- priprema mail i WhatsApp draft
- izvršenje samo kroz backend token
- high-risk potvrde obvezne
