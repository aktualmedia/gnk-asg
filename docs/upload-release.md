# Upload i release — V10

## Cilj
V10 je kompaktan paket za GitHub web upload, s manje od 99 datoteka.

## Koraci
1. Preuzmi i raspakiraj ZIP.
2. U GitHub repo `aktualmedia/gnk-asg` uploadati cijeli folder:
   `zavrsni-model-v19-final-free-ai-agent-tested/`
3. Commit message:
   `Add GNK ASG V10 production-ready preview`
4. Otvori preview:
   `https://gnk-asg.hr/zavrsni-model-v19-final-free-ai-agent-tested/`
5. Otvori self-test:
   `https://gnk-asg.hr/zavrsni-model-v19-final-free-ai-agent-tested/self-test/`
6. Ako self-test prođe, testirati javni AI, privatni agent, MailOps, Communication, Admin, Command i Status.
7. Tek nakon toga napraviti backup stare root stranice.
8. Tek nakon backupa razmatrati promotion na root.
